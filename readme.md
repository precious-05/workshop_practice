# The GitHub Workflow — Workshop Hub

A beginner-friendly static website built for the **Microsoft Learn Student Ambassador** workshop titled:

> **The GitHub Workflow: From Your First Commit to Cloud Deployment**

This site serves as the official information hub for the workshop and is also the live demo project used throughout the session to teach Git, GitHub, GitHub Actions, CI/CD, and Azure Static Web Apps deployment

---

## Features

- Clean, responsive landing page
- Workshop topic overview (Git, GitHub, Actions, Azure)
- Live Demo Status box controlled by a single JavaScript variable
- Interactive workshop checklist with show/hide toggle
- Ready for deployment to Azure Static Web Apps

---

## Technologies Used

- **HTML5** — Semantic page structure
- **CSS3** — Responsive styling with CSS Grid and Flexbox
- **Vanilla JavaScript** — DOM manipulation and interactivity
- **Azure Static Web Apps** — Cloud hosting (Phase 5)

No frameworks, no build tools, no Node.js required. The entire project runs directly in the browser.

---

## How to Run Locally

### Option 1: Open Directly in Browser

1. Download or clone this repository
2. Double-click `index.html`
3. The site opens in your default browser

### Option 2: VS Code Live Server (Recommended)

1. Open the project folder in VS Code
2. Install the **Live Server** extension by Ritwick Dey
3. Right-click `index.html` → **Open with Live Server**
4. The site opens at `http://127.0.0.1:5500` and auto-refreshes on save
